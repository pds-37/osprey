**Phase 5 evidence/provenance:** `metadata.observed` on reachability, risk, and limitation records retains normalized conclusions and the exact shared risk inputs/output. The evidence API exposes these values; SQLite stores them in its existing JSON payload without a schema migration. The canonical ID and record hash cover this structured metadata. Raw source remains hash-only. SHA-256 verification is tamper-evident integrity checking, not immutable storage or chain-of-custody.
**Phase 6 runtime reality:** bounded workspace inspection distinguishes manifest declaration, lockfile resolution, and locally observed installation metadata. No scan launches or attaches to an application. An explicit Python-only instrumentation API can observe an already imported module and a caller-wrapped callable returning successfully; it persists `RUNTIME_OBSERVATION` evidence with analyzer/runtime/process/environment labels, provenance, freshness, limitations, and integrity hashes. Runtime state is `UNKNOWN` without valid current evidence. Static reachability remains independent. See [RUNTIME_REALITY.md](RUNTIME_REALITY.md); runtime evidence is not production telemetry or exploitability proof.
