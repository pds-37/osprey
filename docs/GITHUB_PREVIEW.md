# GitHub Repository Preview

- **Repository title:** OSPREY
- **Short description:** Evidence-driven software supply chain security with vulnerable-symbol reachability, deterministic risk, remediation, verification, and an evidence-grounded Copilot.
- **Social-preview headline:** From vulnerable package to evidence-backed reachability
- **Social-preview subtitle:** Bounded analysis. Deterministic risk. Explicit unknowns.
- **Visual concept:** A restrained dark-on-light or navy-on-white left-to-right flow: dependency/package icon -> highlighted vulnerable function -> a small call-path graph -> evidence card -> risk decision. Use simple vector shapes and a single accent color. Label the graph “bounded static path” and include a small `UNKNOWN` state to signal honest uncertainty. Do not use fake screenshots, fabricated scan metrics, CVE logos, exploit imagery, or claims of production exposure.
